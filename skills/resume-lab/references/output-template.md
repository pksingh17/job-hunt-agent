# Resume Lab output template

Use this structure when a detailed report is useful. Compress it for simple requests.

## Result
- Resume Health: __/100 (for general audit), or
- Estimated ATS Compatibility: __/100 (for JD match)

## Score breakdown
A compact table of dimensions and scores.

## Strong evidence
The most relevant confirmed facts already working in the candidate's favor.

## Underrepresented but confirmed
True skills or experience that can be surfaced more clearly.

## Real gaps
Requirements not supported by the confirmed profile.

## DO NOT ADD
Unconfirmed or absent capabilities that should not be inserted merely for keyword matching.

## Highest-impact changes
Prioritized, concrete edits with the reason each matters.

## Truth audit
Call out any resume claim that is not currently supported by the confirmed profile and requires user confirmation.
