# Security policy

## Reporting

If you discover a vulnerability that could expose credentials, candidate profiles, resumes, application histories, or other sensitive data, **do not post details in a public GitHub issue**. If the project repository supports GitHub private vulnerability reporting, use that feature. Otherwise contact the repository maintainers privately using a channel they have published.

## Supported release

| Version | Security updates |
| --- | --- |
| 1.0.x | Best effort |

## Data handling

Never commit real candidate information, private job trackers, cookies, browser session exports, `.env` files, credentials or API keys. The application controls and privacy policy describe intended boundaries; hosts and third-party websites may impose additional safeguards.
